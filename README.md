## 🌟 Highlights

- **Full Premium Unlocked**  
  Cloud Backups (Google Drive, Dropbox, OneDrive, WebDAV, etc.), Scheduled Backups, and complete app data restoration.
- **Genuine Account & Cloud Sync**  
  Uses the official signed stock APK base combined with systemless bind-mounting (mount -o bind) so Google Sign-In and OAuth services work flawlessly.
- **Smart Conflict Protection**  
  Detects previous signature/package conflicts, safely preserves login and session data from /data/data/org.swiftapps.swiftbackup, installs cleanly, and restores data seamlessly.
- **Play Store Auto-Detach**  
  Automatically detaches the package via zygisk-detach to protect against unwanted Play Store auto-updates.
- **Direct In-App OTA Updates**  
  Supports native one-click updates inside Magisk, KernelSU, and APatch module managers via update.json.

## ⚙️ Installation

1. Open your Root Manager (**KernelSU**, **Magisk**, or **APatch**).
2. Go to **Modules** ➔ **Install from storage**.
3. Select swift-backup-module-v5.1.0-all.zip.
4. Once flashed, open **Swift Backup** and enjoy! *(No reboot required on supported environments)*.
